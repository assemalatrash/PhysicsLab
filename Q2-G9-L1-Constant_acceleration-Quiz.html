💡 Lesson Hints & Formulas

1. Core Definition & Key Ideas

  • Acceleration (a): The rate at which an object's velocity changes over time. Standard SI unit: m/s2.
  • Constant Acceleration: Velocity changes by the exact same amount every single second.
  • Positive Acceleration (+a): Speeding up in the forward direction (vf > vi).
  • Negative Acceleration / Deceleration (−a): Slowing down while moving forward (vf < vi).
  • Zero Acceleration (a = 0 m/s2): Moving at a steady, unchanging velocity (vf = vi).

2. Variables, Units & Keyword Clues

  • vi = Initial velocity (m/s)  |  "Starts from rest" → vi = 0 m/s
  • vf = Final velocity (m/s)  |  "Comes to a complete stop" → vf = 0 m/s
  • t = Time interval (s)
  • a = Constant acceleration (m/s2)
  • d = Displacement / distance in a straight line (m)

3. The 4 Constant Acceleration Formulas

Finding Acceleration
a = vf − vi t
Finding Final Velocity
vf = vi + a · t
Displacement from Rest (vi = 0)
d = 1 2 · a · t2
Displacement with Average Velocity
d = vi + vf 2 · t

4. The 3-Line Math Rule

  • Line 1 (Formula): Write the physics equation using symbols.
  • Line 2 (Substitution): Plug in the given numbers cleanly.
  • Line 3 (Answer): Write the final number with its SI unit inside parentheses, e.g., 12 (m/s).
